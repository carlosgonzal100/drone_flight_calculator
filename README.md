Description: A Program that calculates a drone's estimated flight time based on its payload weight and generates a table
containing the flight times for drones with varying payload weights

Prompts used:

Prompt generated by CHATGPT to create unit tests to test the functions in the flight_calculator.py file.

  "/tests Generate unit 
  tests for the code in flight_calculator.py. Test normal inputs, invalid inputs, boundary cases, and 
  exceptions. Do not change flight_calculator.py. Put the tests in a separate test file"


prompt used to create the calculate_flight_time function in the flight_calculator.py file:

  Implement a function called calculate_flight_time that takes weight in grams(weight_grams).
  It returns active flight time in minutes for a given payload weight using this formula,   
  T(w) = 180 - 0.1w. T is the resulting active flight time in minutes, and w is payload weight in
  grams, which must be greater than or equal to 0 grams. If the formula produces a negative value,  
  return 0; if weight_grams is less than 0, raise a ValueError with the message "Weight must be 
  greater than or equal to 0 grams."


prompt used to create the flight_time_table function in the flight_calculator.py file:

  create a function called flight_time_table that takes in max weight in grams(max_weight_grams),
  and step_grams. The function returns a list of (weight, flight_time) pairs for payload weights
  from 0 up to and including max_weight_grams, in increments of step_grams. The function must internally
  call calculate_flight_time() for each weight rather than recalculating the formula
